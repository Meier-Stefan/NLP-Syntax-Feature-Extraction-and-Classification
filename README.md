## Get Started

This project is initialised with `uv`. (Using the `--bare` flag to get a minimal setup for the scripts.)  

To install the dependencies it is easiest to have `uv` installed and then run the command `uv sync` from the source of the folder. Then, activate the environment via `source .venv/bin/activate`.  

The scripts can then be run via `python PartOne.py`.  

For `PartThree.py`, further installation instructions can be found in `/answers/appendix.md`. Answers for the questions in the brief can be found in `/answers`. Sample outputs of all scripts can be found in `/outputs`.
